# Student Management Dashboard

This project is a **React.js frontend application** that manages a list of students.  
It allows users to **add, edit, delete, search, sort, and download student data** in Excel format.

This project was developed as part of a **Full Stack Assignment – Students Table**.

---

## Live Demo

Live Application:  
https://students-table-h94o.vercel.app/

GitHub Repository:  
https://github.com/Theju2110/students-table

---

## Features

- Display students in a table (Name, Email, Age)
- Add new students with validation
- Edit existing student details
- Delete students with confirmation dialog
- Search students by name
- Sort students by name
- Export student data as an Excel file
- Data persistence using localStorage
- Responsive and clean UI

## Installation and Setup

1. Clone the repository

git clone https://github.com/Theju2110/students-table.git


2. Navigate to the project directory

cd students-table

3. Install dependencies

npm install

4. Run the Project

npm start


The application will run on:

http://localhost:3000
